# NAP-EX Backend — الخادم المركزي

خادم FastAPI للمنصة الوطنية لمكافحة الابتزاز الإلكتروني:
استقبال البلاغات من تطبيق الضحية، تحليل الأنماط (كشف المبتزين المحترفين)،
إدارة القضايا، سلسلة حفظ الأدلة، وبث فوري عبر WebSocket للوحة التحكم.

## التشغيل المحلي

```bash
cd backend
pip install -r requirements.txt
uvicorn app.main:app --reload --port 8000
```

- التوثيق التفاعلي: http://localhost:8000/docs
- فحص الصحة: http://localhost:8000/health

**حسابات لوحة التحكم التجريبية** (تُنشأ تلقائياً عند أول تشغيل):

| الدور | الهاتف | كلمة المرور |
|---|---|---|
| مدير | +967000000000 | Admin@123 |
| محقق | +967000000001 | Inv@123 |
| مشرف | +967000000002 | Sup@123 |

**OTP في وضع التطوير:** أي رمز من 6 أرقام يُقبل (`DEV_ACCEPT_ANY_OTP=true`).
عطّله في الإنتاج حتماً — حينها يُولَّد رمز حقيقي ويُسجل في سجل الخادم (ويُستبدل لاحقاً بمزود SMS).

## الواجهات (prefix /api/v1)

| Endpoint | الوصف | من يصل |
|---|---|---|
| `POST /auth/register` | تسجيل ضحية + توليد OTP | عام |
| `POST /auth/verify-otp` | تحقق → JWT (access+refresh) | عام |
| `POST /auth/login` | دخول لوحة التحكم | عام |
| `POST /auth/refresh` / `logout` / `GET me` / `DELETE account` | دورة الجلسة | مصادق |
| `POST /reports` | **استقبال بلاغ من التطبيق** → رقم رسمي EXT-YYYY-XXXXXX | مصادق |
| `GET /reports` + فلاتر (status, q, page) | قائمة/بحث البلاغات | محقق/مشرف/مدير |
| `GET /reports/{id}` | التفاصيل + الأدلة + سلسلة الحفظ | محقق/مشرف/مدير |
| `PATCH /reports/{id}/status` | تحديث حالة القضية (موثق + بث) | محقق/مشرف/مدير |
| `POST /evidence/upload` | رفع دليل + تحقق SHA-256 | مصادق |
| `GET /evidence/{id}` | تنزيل الدليل | محقق/مشرف/مدير |
| `POST /analysis/classify` | تصنيف نص على الخادم | مصادق |
| `GET /analysis/patterns` | **كشف المبتزين المحترفين** | محقق/مشرف/مدير |
| `GET /stats/overview` | إحصاءات لوحة التحكم | محقق/مشرف/مدير |
| `WS /ws?token=` | بث فوري: new_report / status_change | توكن صالح |

## تحليل الأنماط — كيف يكشف المبتز المحترف؟

يجمع الخادم البلاغات حسب `sender_hash` ويحسب لكل مُرسل:
عدد الضحايا، عدد البلاغات، التطبيقات المستخدمة، مدة النشاط، متوسط الثقة.

**يُصنّف "محترفاً" عندما:** ضحيتان أو أكثر، أو 4 بلاغات أو أكثر.
درجة الخطورة = `ضحايا×3 + بلاغات + تطبيقات (+5 إذا امتدت الحملة ≥ 30 يوماً)`.

## سلسلة الحفظ (Chain of Custody)

كل إجراء يُوثق بجدول `custody_entries`: استلام البلاغ من الجهاز، استلام الدليل
(مع نتيجة مطابقة الهاش)، كل تغيير حالة مع المُجري والملاحظة. بالإضافة إلى `audit_logs`
لكل إجراء إداري.

## ⚠️ قبل الإنتاج

1. `SECRET_KEY` عشوائي طويل + `DEV_ACCEPT_ANY_OTP=false`
2. Postgres بدل SQLite (`DATABASE_URL`)
3. تكامل مزود SMS حقيقي لإرسال OTP
4. HTTPS + rate limiting (مثلاً خلف nginx)
5. غيّر كلمات مرور الحسابات التجريبية أو احذفها
